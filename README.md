# MyPortfolio

## About the Project

MyPortfolio is a simple portfolio website created as part of my **IT Elective 2** subject. It is an ASP.NET Core MVC application that showcases my projects, activities, and outputs throughout the course.

The website includes project descriptions, thumbnail images, GitHub project links, project detail pages, and a login page.

## Features

* Hardcoded Login
* Portfolio Project List
* Table of Contents
* Project Thumbnail Images
* Project Descriptions
* Project Detail Pages
* GitHub Project Links
* Comment Section for Projects
* Responsive and simple user interface

## Technologies Used

* C#
* ASP.NET Core MVC
* HTML
* CSS
* Razor Views
* Visual Studio
* GitHub
